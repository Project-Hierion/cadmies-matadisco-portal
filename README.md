# matadisco-cadmies-portal

Dedicated viewer and indexer for CADMIES concepts on the Matadisco network.

## Purpose

A specialized portal for scientists and academics to discover and explore CADMIES knowledge graph concepts through the Matadisco decentralized data network.

## Architecture

- **Backend:** Python indexer + API
- **Frontend:** HTML/CSS/JS
- **Data:** SQLite
- **Source of truth:** `concepts.json` (same as CADMIES gateway)
